### Hi, I'm Clark (Qingjie) Shen

A product manager who designs, builds and ships with AI coding tools. I find the user problem, decide what to build, design it, write the code with Claude Code and other coding agents, ship it, and measure what happens.

**What I've built**

It turns lot photos into studio-quality listings and videos, and includes Movo, an AI agent that proposes changes for a person to confirm. 1,164 commits, 164 merged pull requests, about 1,985 automated tests.
- **Atelier** (November 2026): turns an interior designer's hand-measured sketches and AutoCAD drawings into checked floor plans and a 3D walkthrough.

📂 **Case studies with screenshots, decisions and results: [motivoai-showcase](https://github.com/QingjieShen/motivoai-showcase)**. The product code is private; I'm glad to walk through it live.

**How I build with AI**

- A test that reproduces the bug comes before every fix.
- Each feature ships with its tests and its in-app tip.
- No pull request merges until the whole test suite passes.
- Decisions are written down with their reasons, so the next session, human or AI, keeps them.
